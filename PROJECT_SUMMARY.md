## 🚀 How to Deploy

### Option 1: GitHub Pages (Recommended - FREE)
Most popular for portfolios and demos

```bash
# 1. Create docs folder and copy dashboard
mkdir docs
cp src/frontend/vacation_dashboard.html docs/index.html

# 2. Push to GitHub
git add docs/index.html
git commit -m "Add GitHub Pages"
git push

# 3. Enable in GitHub Settings → Pages
# Set source: main branch, /docs folder

# Result: https://YOUR_USERNAME.github.io/vacation-planner-2026/
```

### Option 2: Netlify (FREE, Easier)
Drag-and-drop deployment

```bash
npm install -g netlify-cli
netlify deploy --prod --dir=src/frontend
```

### Option 3: Vercel (FREE)
Made for web apps

```bash
npm install -g vercel
vercel --prod
```

### Option 4: Custom Domain
Use any hosting service and point domain to GitHub Pages
