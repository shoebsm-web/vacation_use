# 🚀 Deploy SkyPulse to Vercel (1-Click Setup)

## What This Does

Deploys your SkyPulse flight booking platform completely live with:
- ✅ Frontend working
- ✅ Backend API working
- ✅ No API keys needed (mock data)
- ✅ Fully functional
- ✅ Zero configuration

## Deploy Now

### **Click This Link:**
https://vercel.com/new/clone?repository-url=https://github.com/shoebsm-web/vacation_use

### **Then:**
1. Click "Create"
2. Wait 1 minute
3. Click "Visit"
4. **That's it!** Everything works! 🎉

---

## What Happens

1. Vercel clones your GitHub repository
2. Automatically detects the serverless function in `/api/flights.js`
3. Deploys frontend to Vercel CDN
4. Deploys backend API to Vercel serverless
5. Gives you a live URL

**Example:** `https://vacation-use.vercel.app/`

## Customize Later

To add real flight APIs:
1. Get API keys from SerpAPI, RapidAPI, etc.
2. Add to Vercel environment variables
3. Update `/api/flights.js` to use real APIs

(But mock data works great for now!)
